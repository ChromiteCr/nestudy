# S3 阶段设计（已批准）

> 批准日期：2026-07-19。范围：Activity 实体 + 项目时间轴 + 成果模块化网络图。
> 立意：**以个人成长为中心的成长网络**（节点=内容性/实质性的部分：活动、课程、未来的反思），目标校作为最终指向的锚点，而非组织中心。

## 立意与关键决策（来自用户）
- Activity 实体：**完整 CRUD + AI 提案**（复用 S2「提案→确认卡→入库」模式）。它是 S4 反思、S5 skill 的共同地基。
- 叙事线（边）：**AI 提案 + 手动微调**——AI 分析活动间主题关联 propose 一组连线（含"为什么连"说明），用户在图上可增删。
- 节点构成：活动 + 课程 + 目标校锚点；**节点层设计为可扩展**，S4 反思作为节点无缝接入。成长为中心，最终指向申请成功。

## 1. Activity 实体（Dexie v3，S3 地基）

`activities` 表：
- id、title、category（academic/leadership/service/athletics/arts/work/research/other）
- role、organization
- startDate、endDate（ISO 或 null=进行中）
- description、achievements[]（字符串数组）
- level（school/regional/national/international）
- source（manual/ai）、createdAt

CRUD：planningStore 扩展或新建 activityStore；ActivitiesView 手动增删改查。
AI 提案：`propose_activities` 工具 + 活动提案卡（复用 ProposalCard 模式，Proposal 增 `kind: 'activities'`）。

## 2. 叙事线持久化（Dexie v3）

`narrativeEdges` 表：id、sourceNodeId、targetNodeId、label（为什么连）、source（ai/manual）、createdAt。
- 节点 id 采用带前缀的稳定 id：`activity:<id>` / `course:<id>` / `school:<id>`（未来 `reflection:<id>`），使边跨实体类型稳定引用。
- `propose_narrative` 工具：AI 给出一组 {sourceLabel, targetLabel, reason}，按标题解析为节点 id，出提案卡确认后写入。

## 3. 项目时间轴（学期鸟瞰）

自研轻量横向时间轴（不引库；React Flow 只给网络图）：
- 聚合：events（考试/DDL/活动点）+ activities（有起止 → 时间跨度条）+ tasks（到期点）
- 按月分列，今日标记线，倒计时；点击项目跳转到任务/活动
- 组件：`TimelineView`，纯 flex/SVG，响应式（窄屏可横向滚动）

## 4. 成果模块化网络图（React Flow / @xyflow/react）

- **节点映射层** `buildGraphNodes()`：读 activities + courses + targetSchools，映射为统一 `GraphNode { id, type, label, category?, meta }`。S4 反思只需在此加一路映射。
- 节点视觉：活动按 category 着色、课程为辅节点、目标校为锚点（不同形状/置顶）。
- 边：来自 `narrativeEdges`；React Flow 上支持手动连线（onConnect→写 manual 边）与删除。
- `propose_narrative` 生成的边经确认卡入库后渲染。
- 布局：初始用简单力导或分层布局（dagre 可选；先用 React Flow 自带 + 分类分列的初始坐标），用户可拖动，坐标持久化到 narrativeEdges 同表或 nodePositions（`graphLayout` 表，可选）。

## 5. 版本节奏（对齐全局规则；S2a 为修复系列，中版本续 S2b）
S2b Activity 模型 + CRUD + AI 提案 → S2c 项目时间轴 → S2d 成果网络图（React Flow + 叙事线）→ 阶段完成升 **S3**。

## 6. 复用与新增
- 复用：ProposalCard / agent loop / planningStore 模式 / 提案确认制
- 新增依赖：`@xyflow/react`（React Flow v12）
- 侧栏「时间轴」「成果网络」解禁；活动入口（侧栏或档案区）
