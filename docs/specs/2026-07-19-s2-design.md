# S2 阶段设计（已批准）

> 批准日期：2026-07-19。范围：Profile+Onboarding、任务+Dashboard、粘贴即导入、主动式 Agent v1。
> 明确跳过：北京服务器免费代理（备案后再做）。压测列入计划暂不实施（见 §5）。

## 1. 数据模型（Dexie schema v2，两表分开）

- `profile`（单例，id='app'）：grade、curriculum('IB'|'AP'|'ALevel'|'Other')、courses[]（name/level/currentGrade/targetGrade）、targetSchools[]（name/major/round/deadline）
- `events`：id、title、type('exam'|'deadline'|'activity')、date、source('manual'|'import'|'ai')、createdAt
- `tasks`：id、title、dueDate、priority('high'|'medium'|'low')、status('pending'|'completed')、parentEventId?、createdAt
- 分表理由：DDL 是"事实"，任务是"行动"，一对多拆解；S3 时间轴与优先级引擎的地基
- JSON 导出/导入同步扩展

## 2. AI 工具调用管道（核心架构新增）

- `ChatProvider` 流式事件升级：`text | tool_calls` 两类；支持 tools 参数
- chatStore 实现 agent loop（≤4 轮）
- **「AI 提案 → 卡片确认 → 入库」模式**：AI 不直接写库
  - 提案工具：`propose_import`（events+tasks 批量）、`propose_profile_update`（档案补丁）→ 聊天流渲染可编辑确认卡，用户确认才写 Dexie
  - 读工具：`get_profile`、`get_tasks`、`get_events` → 自动执行
- 该模式同时服务粘贴导入、Onboarding，并作为 S5 skill 执行的原型

## 3. 功能形态

- **任务视图**：侧栏「任务」解禁；今日/全部/DDL 三个 tab；CRUD+勾选完成
- **Dashboard 真实化**：今日任务卡（可勾选）、近期 DDL 卡（倒计时）、档案摘要卡（空态显示建档 CTA）
- **粘贴即导入**：composer 旁「导入」按钮 → 弹窗粘贴 → AI 解析 → 预览卡逐条可编辑 → 确认入库；聊天内同工具可触发
- **Onboarding**：档案为空时 Dashboard 顶部引导卡 → 进入对话，AI 逐项采访 + 嵌入式表单卡确认；档案可在 Dashboard 点开手动编辑（表单弹窗兜底）
- **主动式 Agent v1**（`lib/engine/`）：打开应用时检测规则 → Dashboard 顶部可关闭提醒卡 + 「去处理」跳转对话（预置上下文）
  - R1 某 DDL≤7 天且无关联任务
  - R2 今日到期任务>5 条或昨日完成率<50%
  - R3 距上次活跃≥3 天（settings 记 lastActiveAt）
  - R4 档案缺关键字段（无课程/无目标校）

## 4. 版本节奏

S1b 数据模型+任务+Dashboard → S1c 工具管道+粘贴导入 → S1d Onboarding+档案 → S1e 主动引擎 → 阶段完成升 **S2**
